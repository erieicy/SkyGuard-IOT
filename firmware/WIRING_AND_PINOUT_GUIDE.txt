================================================================================
  SKYGUARD AI - PANDUAN SKEMATIK & PINOUT HARDWARE (JEMURAN PINTAR IoT)
================================================================================
  Sistem ini terdiri dari dua modul mikroprosesor:
  1. Modul Utama: ESP32-S / ESP32 DevKit V1 (Kontrol Sensor & Motor Atap)
  2. Modul Kamera: ESP32-CAM AI-Thinker OV2640 (AI Vision Langit & Sumber Cahaya)
================================================================================

[1] DAFTAR KOMPONEN (BILL OF MATERIALS):
--------------------------------------------------------------------------------
1. 1x ESP32 NodeMCU DevKit V1 (30 Pin / 38 Pin)
2. 1x ESP32-CAM AI-Thinker + Modul Kamera OV2640
3. 1x Sensor Air Hujan (Raindrop Sensor Module + Driver LM393)
4. 1x Sensor Cahaya LDR (Light Dependent Resistor) + Resistor 10k Ohm (atau Modul LDR)
5. 1x Motor Servo Metal Gear MG996R (atau SG90 untuk miniatur/prototype jemuran)
6. 1x Modul Relay 5V (Opsional, jika memakai Motor DC Linear Actuator)
7. 1x Buzzer Aktif 5V (Peringatan audio saat hujan/mendung)
8. 1x Power Supply / Adaptor 5V 2A-3A (Disarankan power eksternal untuk Servo)
9. Kabel Jumper (Male-to-Female, Male-to-Male)
10. Rangka Miniatur Jemuran Baju dengan Atap Geser/Canopy Lipat

*CATATAN PENTING SERVO*:
Servo MG996R menarik arus hingga 1.5A saat bergerak. JANGAN mengambil daya 5V dari pin ESP32 
secara langsung karena dapat menyebabkan ESP32 restart (brownout). Gunakan catu daya 5V terpisah 
untuk servo, lalu hubungkan GND power supply ke GND ESP32 (Common Ground).

[4] CARA KERJA SISTEM LOGIKA SKYGUARD AI:
--------------------------------------------------------------------------------
1. LOGIKA AIR & HUJAN:
   - Modul sensor air mendeteksi tetesan hujan pada pelat sensor.
   - Jika air menyentuh sensor (Active LOW), ESP32 secara instan (< 100ms) memutar servo
     ke sudut 0 derajat (Atap TERTUTUP RAPAT) dan membunyikan alarm buzzer.
   - Status terkirim ke REST API Dashboard `api/esp32.php`.

2. LOGIKA CAHAYA & AI VISION:
   - Sensor LDR membaca apakah terdapat cahaya terang di sekitar jemuran.
   - Jika ada cahaya, ESP32-CAM mengambil foto sudut atas (menghadap langit).
   - Server AI SkyGuard menganalisis citra:
     * APAKAH CAHAYA MATAHARI? -> AI mengonfirmasi spektrum matahari alami -> Atap DIBUKA.
     * APAKAH HANYA LAMPU BIASA? -> AI mendeteksi spektrum lampu bohlam/LED ruangan -> Atap TETAP TERTUTUP.
     * APAKAH CUACA MENDUNG? -> AI mendeteksi awan gelap kumulonimbus -> Atap DITUTUP & Dashboard memberi peringatan bahaya hujan.

3. LOGIKA STOPWATCH & TIMER PINTAR:
   - Pengguna dapat mengatur waktu jemur via Dashboard (misal: 30 menit atau rekomendasi AI).
   - Dashboard menghitung mundur waktu secara real-time.
   - Ketika timer habis (00:00), atap otomatis ditutup agar pakaian tidak terpapar debu malam/kelembaban.

4. MODE KONTROL:
   - Mode OTOMATIS: Sistem bekerja mandiri berdasarkan AI cuaca, matahari, dan sensor air.
   - Mode MANUAL: Pengguna bebas membuka/menutup atap kapan saja lewat tombol dashboard.
   - Mode TIMER: Atap terbuka selama durasi yang ditentukan lalu tertutup otomatis.

--------------------------------------------------------------------------------
[5] LANGKAH PENGUJIAN AWAL:
--------------------------------------------------------------------------------
1. Buka folder dashboard di browser: http://localhost/SkyGuard-AI/
2. Isi IP ESP32 di kolom WiFi dashboard, lalu hubungkan ESP32 ke Wi-Fi sama dengan Laptop XAMPP.
3. Upload kode `esp32_firmware.txt` ke ESP32 melalui Arduino IDE.
4. Upload kode `esp32_cam_firmware.txt` ke ESP32-CAM.
5. Pastikan ESP32 dan Laptop/Server XAMPP berada dalam satu jaringan Wi-Fi yang sama.
